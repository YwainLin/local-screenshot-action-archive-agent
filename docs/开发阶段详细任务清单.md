- [ ] 编写状态图基础测试

### 3.2 Neo4j 图存储（graph_store）
- [ ] 安装并配置本地 Neo4j Community 实例
- [ ] 集成 `neo4j-graphrag` 库
- [ ] 实现图模型导入：
  - `(:Asset)-[:HAS_OCR]->(:OcrChunk)`
  - `(:Asset)-[:DUPLICATE_OF {kind, distance}]->(:Asset)`
  - `(:Asset)-[:MENTIONS {confidence, evidence_span}]->(:Entity)`

- [ ] 实现实体类型约束：`date`、`url`、`amount_candidate`、`order_candidate`、`action_phrase`

## 依赖关系

```
阶段 0（安全骨架）
    ↓
阶段 1（只读索引）
    ↓
阶段 2（本地 OCR 与搜索）
    ↓
阶段 3（LangGraph + GraphRAG 候选计划）
    ↓
阶段 4（受控复制与展示）
```

阶段 0 是所有后续阶段的前置。阶段 1-4 严格顺序依赖。阶段内子任务可部分并行。
