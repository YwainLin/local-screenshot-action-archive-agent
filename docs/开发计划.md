## 阶段 0：安全骨架（预计 2-3 天）

### 0.1 项目基础搭建
- 初始化 Python 项目（`pyproject.toml`、`requirements.txt`）
- 配置 `black`、`ruff`、`mypy` 代码质量工具
- 创建 `.gitignore`（排除工作区、SQLite、缩略图、模型缓存等）
- 搭建基础目录结构：`app/api/`、`app/services/`、`app/agent/`、`app/storage/`、`tests/`

### 0.2 工作区白名单与配置
- 定义 `config.json` schema（Pydantic 模型）
- 实现工作区创建与验证逻辑
- 白名单目录扫描限制

### 0.3 数据库迁移框架
- SQLAlchemy/Alembic 或 SQLite 手动迁移脚本
- 创建 `scan_run`、`asset`、`duplicate_group`、`ocr_result`、`extraction`、`archive_proposal`、`audit_event` 7 张核心表
- 编写数据库初始化脚本

### 0.4 脱敏测试样例
- 创建自制脱敏截图样例（相同文件、不同压缩、近似图片、中英文、低清晰度等）
- 验证 `.gitignore` 不会泄露真实数据

### 0.5 README 初始化
- 创建基础 `README.md`（项目名称、简介、安装说明占位）

**验收：** 项目可安装、可运行、数据库可初始化、测试样例可加载

## 阶段 1：只读索引（预计 3-4 天）

### 1.1 扫描器（scanner）
- 实现白名单后缀过滤（`.png`、`.jpg`、`.jpeg`、`.webp`）
- 读取文件元数据（路径、大小、mtime）
- 创建 `list_assets` 工具函数

### 1.2 图像指纹（image_fingerprint）
- SHA-256 哈希计算
- pHash/dHash 感知哈希（Pillow/OpenCV）
- 缩略图生成（固定尺寸）
- 创建 `fingerprint_image` 工具函数

### 1.3 重复检测
- 完全重复组：SHA-256 相同的文件聚合
- 近似重复组：pHash 距离计算，配置阈值
- 写入 `duplicate_group` 表

### 1.4 扫描 API
- `POST /api/v1/scans` 提交扫描任务
- `GET /api/v1/scans/{id}` 查询进度
- `GET /api/v1/assets` 查询资产

### 1.5 扫描结果页面
- `/runs/{id}` 展示文件数、重复组、OCR 状态

**验收：** 可扫描目录、计算哈希、识别重复组、API 可调用、页面可展示

---

## 阶段 2：本地 OCR 与搜索（预计 3-4 天）

### 2.1 OCR 服务（ocr_service）
- 集成 PaddleOCR 或 Tesseract
- 实现 `run_local_ocr` 工具函数
- 存储 OCR 结果（文本、语言、置信度、引擎版本）

### 2.2 规则提取（extractor）
- 日期/时间模式匹配
- URL 链接提取
- 金额模式识别（`¥\d+.\d+`）
- 行动词识别（"截止"、"领取"、"预约"、"待处理"）
- 敏感候选标记（`sensitive_candidate`）

### 2.3 索引存储（index_store）
- SQLite FTS5 全文搜索
- 关键词/日期/标签查询接口

### 2.4 敏感掩码处理
- 验证码/一次性口令不提取为行动项
- 长数字串/银行卡疑似文本部分掩码
- 地址/电话/姓名默认不出现在导出摘要

### 2.5 搜索页面
- `/search` 关键词/日期/标签查询与图片预览
- `/actions` 行动项展示（OCR 证据、日期候选、待办状态）

**验收：** OCR 可运行、规则可提取、搜索可返回结果、敏感信息可掩码

## 阶段 3：LangGraph + GraphRAG 候选计划（预计 4-5 天）

### 3.1 LangGraph 状态图实现
- 定义状态节点：inventory → deduplicate → ocr_extract → graph_index → retrieve_and_plan → approval_interrupt → apply_copy/record_feedback → audit
- 实现 LangGraph 编排逻辑
- SQLite checkpoint 持久化

### 3.2 Neo4j 图存储（graph_store）
- 搭建本地 Neo4j Community 实例
- 实现图模型导入（Asset、OcrChunk、Entity、ActionItem、ArchiveProposal、Category）
- `neo4j-graphrag` 集成

### 3.3 检索与计划生成
- SQLite FTS 候选获取
- Neo4j 有限关系扩展（重复、实体、行动、建议）
- `build_proposals` 工具函数生成归档计划

### 3.4 证据链与置信度
- 每条计划必须带 `asset_id` 和原始证据
- 低置信度建议标记为"需要人工确认"
- 模型生成的实体标记 `model_suggestion`

### 3.5 审批中断状态机
- 审批页面 `/proposals`（单条确认、修改目标、拒绝理由）
- API：`POST /api/v1/proposals/generate`、`approve`、`reject`

**验收：** LangGraph 可编排、Neo4j 可导入、归档计划可生成、审批可中断

## 阶段 4：受控复制与展示（预计 2-3 天）

### 4.1 文件操作（file_operator）

### 4.2 审计日志
- 只追加 `audit_event` 记录
- 记录：proposal_id、event_type、before_hash、after_hash、timestamp

### 4.3 审计日志页面
- `/audit` 已批准复制/导出操作及哈希展示

### 4.4 README 与文档
- 项目 README.md（安装、使用、架构说明）
- 隐私与数据边界文档

### 4.5 演示准备
- 脱敏演示录屏
- 公开示例集准备

**验收：** 复制可受控执行、审计日志完整、文档齐全、可演示
